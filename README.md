# Projeto: Barbearia Modelo - Portfólio Gomark

Projeto desenvolvido em React + Vite + Tailwind CSS.

## Como executar localmente
1. Abra o terminal na pasta do projeto.
2. Instale as dependências: `npm install`
3. Rode o servidor local: `npm run dev`
4. Acesse o link informado no terminal (geralmente http://localhost:5173).

## Como editar as informações
Todas as informações da barbearia (nome, telefone, preços, links de imagens e endereço) estão centralizadas no arquivo `src/config.js`. Edite apenas este arquivo para personalizar o site para um cliente real.

## Como publicar
1. Envie o código para o seu repositório no GitHub.
2. Acesse a Vercel (vercel.com) e crie um novo projeto importando esse repositório.
3. A Vercel configurará o build automaticamente (Framework: Vite).
4. Clique em "Deploy" e o site estará no ar.
